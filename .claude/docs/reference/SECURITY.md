# Security

Trace untrusted requests across localhost/origin enforcement, input validation, SQL, filesystem paths, provider calls, and trainer routing. Check credential encryption context/key persistence, owner isolation, redirect/DNS/SSRF defenses, request bounds, artifact traversal, and log redaction. Protect checkpoints/backups and do not silently rotate keys. Port conflicts never justify killing unrelated processes or containers. Report plausible exploitation paths with file/line evidence; distinguish them from general hardening advice.

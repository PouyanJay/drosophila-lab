# Beautiful Mermaid

Ground nodes and edges in actual code/data flow. Keep labels short, distinguish browser/Next.js/trainer/database boundaries, and show provenance or lifecycle transitions when they matter. Prefer a small native Mermaid block for repository docs. For a requested standalone rendered artifact, use an available renderer, validate syntax, inspect the output and link it. Do not claim a diagram was rendered without opening the output. Avoid installing a rendering service or introducing framework dependencies for a simple documentation diagram.

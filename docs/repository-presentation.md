# Repository presentation

The GitHub About description and topics are recorded in [repository-metadata.json](../.github/repository-metadata.json). GitHub does not apply this file automatically; keep the live repository settings and this record in sync when the project's scope changes.

## Discovery terms

- **Domain:** `drosophila`, `malecns`, `connectomics`, `connectome`, `computational-neuroscience`, `neuroscience`, `brain-atlas`. These describe the measured dataset and the atlas/research workflow.
- **Research:** `neuroai`, `brain-inspired-ai`, `neural-architecture-search`, `neural-networks`, `scientific-computing`, `reproducible-research`. These describe the model experiments and bounded structural-search worker; they do not imply biological fidelity or superior performance.
- **Implementation:** `data-visualization`, `threejs`, `pytorch`, `webgpu`, `python`, `typescript`. These help people looking for the implemented visualization and compute tools.

The selection uses the actual code and protocols, the [official MaleCNS project](https://male-cns.janelia.org/), and established GitHub topic communities for [connectomics](https://github.com/topics/connectomics), [computational neuroscience](https://github.com/topics/computational-neuroscience), and [neural architecture search](https://github.com/topics/neural-architecture-search). Dataset-specific terms complement the broader communities. Avoid unrelated trending tags or unsupported claims such as whole-fly emulation, embodied intelligence, or validated general-purpose superiority.

## Maintenance

Use a real workspace capture for the README preview; see [image provenance](assets/README.md). Keep badges linked to actual workflows, dependency manifests, and licenses. The code's MIT license and the data's CC BY attribution are separate. Do not add a live-demo or passing-test badge that implies an unavailable deployment or unverified result.

Issue forms request reproducible context and exclude secrets. The pull-request template distinguishes verification from scientific interpretation.

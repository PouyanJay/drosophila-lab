# Agent-driven discovery preview

[Open the interactive preview](discovery-concepts.html). This extends the existing conversation, atlas and evidence drawer. It is a design artifact, not a running discovery service.

## Evidence views

- [Activity](discovery-activity.png): research events and campaign details.
- [Experiments](discovery-experiments.png): proposed comparisons and evidence status.
- [Lineage](discovery-lineage.png): source, descendants and custom modules.

The atlas image is a read-only capture of the current local app. Agent text and campaign states are illustrative; no measured discovery results are represented. Preview controls only change this page. The earlier standalone layout concepts are superseded.

Browser verification covered all three views, lineage selection, collapse and inspect controls, illustrative pause/resume, and horizontal overflow at a 390-pixel viewport. The atlas itself is static in this preview. Production mobile navigation remains the existing Conversation/Atlas/Evidence pattern described in the [full plan](../agentic-discovery-plan.md).
